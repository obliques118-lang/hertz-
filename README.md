# Hertz – Synchronized Audio Streaming

Dark‑themed, glassmorphism web app for host‑controlled audio playback synced across multiple receiver devices.

## Features
- Role selection (Host / Receiver)
- Host uploads an audio file and controls playback (play, pause, seek, volume)
- Receiver joins by scanning a QR code (camera) and listens perfectly synced
- Shared chat & song suggestions
- Neon‑accented glassmorphism UI, mobile‑responsive
